# digital_domain

This repository contains the following projects:

## 1. Async_fifo
An asynchronous (dual-clock) FIFO design for safe data transfer across independent clock domains, using gray-coded pointers and synchronizers to avoid metastability.

## 2. SRAM_based_LUT_Design
An SRAM-based Look-Up Table (LUT) design, implemented through Cadence Virtuoso.

---
Each project folder contains its own source files and further details.
